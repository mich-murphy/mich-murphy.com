{{- /* A page's h2 and h3 headings in document order, as a list of dicts: id, level and title. Contents uses it. .Fragments.Identifiers is sorted, so it walks .Fragments.Headings instead, a tree: posts start at h2, so its top level is one placeholder with no id, the h2s under it and the h3s under those. A heading without an id, or at another level, is skipped, and its children still count. Hugo gives each title as HTML, so & comes as &; title is plain text, which a template escapes once. Call it with a page, or with a list of headings as it does for each level */}} {{- $hs := . }} {{- if not (reflect.IsSlice .) }}{{ $hs = .Fragments.Headings }}{{ end }} {{- $out := slice }} {{- range $hs }} {{- if and .ID (ge .Level 2) (le .Level 3) }}{{ $out = $out | append (dict "id" .ID "level" .Level "title" (.Title | plainify | htmlUnescape)) }}{{ end }} {{- /* only a list with headings in it: append spreads a list of dicts into $out, but adds an empty one whole, as an element, and a heading whose children are all h4s or below gives an empty one. Contents would read it as a heading, and fail the build */}} {{- with .Headings }}{{ with partial "headings.html" . }}{{ $out = $out | append . }}{{ end }}{{ end }} {{- end }} {{- return $out }}
