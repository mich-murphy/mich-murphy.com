Contents box lab

On a phone the Contents button sits 16px in from the edge, the same as a code window's frame. As a window scrolls past, the button's right edge runs along the window's border, and the two read as one box. The open box has the same problem across its full width, and D, the dimmed page, settles that. Each phone below is the real post with one treatment. Scroll any of them, or use the scroll control, to move all six together. On the button set, tap a button to open the box with D.
