# My Personal Website - [mich-murphy.com](https://mich-murphy.com/)

## Purpose
Created to document my personal projects, for my own reference and hopefully to help anyone else working on similar things.

## Components
This is a static site built using [Hugo](https://gohugo.io/) with the [Bear Cub](https://github.com/clente/hugo-bearcub) theme, which I've extended and customised. A Nix flake provides the local development environment, and the site is built and deployed to [GitHub Pages](https://pages.github.com/) by the official Hugo GitHub Actions workflow.
